Política de privacidad — El Coco Uploader

Última actualización: 9 de noviembre de 2026

El Coco Uploader («la aplicación») es una herramienta privada que usa el titular del canal de YouTube «El Coco Te Lo Explica!» para subir y programar sus propios vídeos. Esta política explica qué datos trata.

1. Quién la usa

Solo el titular del canal. La aplicación no se ofrece al público, no tiene registro de usuarios y no accede a cuentas de terceros.

2. Datos a los que accede

Mediante el inicio de sesión de Google (OAuth 2.0) y con el permiso expreso del titular, la aplicación usa los ámbitos youtube.upload y youtube de la API de datos de YouTube exclusivamente para:

  • subir vídeos y miniaturas al canal propio;
  • poner o cambiar título, descripción, etiquetas, visibilidad y fecha de publicación de esos vídeos;
  • consultar el estado de procesamiento de los vídeos subidos.

No lee comentarios, mensajes, suscriptores, historial ni datos personales de otras personas.

3. Dónde se guardan

El token de acceso que emite Google se guarda únicamente en el ordenador del titular del canal. No hay servidores propios ni bases de datos externas. Los vídeos y metadatos se envían solo a YouTube (Google).

4. Con quién se comparten

Con nadie. No se venden, ceden ni comparten datos con terceros, ni se usan para publicidad. El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

5. Cómo revocar el acceso

El titular puede retirar el permiso en cualquier momento desde myaccount.google.com/permissions y borrar el token local. También se aplican las Condiciones del servicio de YouTube y la Política de privacidad de Google.

6. Contacto

English summary

El Coco Uploader is a private, single-user tool used only by the owner of the YouTube channel “El Coco Te Lo Explica!” to upload and schedule their own videos via the YouTube Data API (scopes youtube.upload and youtube). OAuth tokens are stored only on the owner’s computer. No data is sold, shared with third parties or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: afiliatetest7@gmail.com.
